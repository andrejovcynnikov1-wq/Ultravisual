# ULTRA VISUAL (Fabric 1.21.11)

- ESP-боксы игроков сквозь блоки до 400 блоков
- Радужная «китайская шляпа» на цели, ближайшей к прицелу
- Right Shift: серое HUD-меню с названием ULTRA VISUAL и счётчиком FPS в реальном времени (Esc закрывает)

## Сборка jar
Вариант А (локально): JDK 21 + IntelliJ IDEA, открыть папку, Gradle -> build. Jar: build/libs/ultravisual-1.0.0.jar
Вариант Б (без установки): залить папку в GitHub-репозиторий, вкладка Actions -> build -> скачать артефакт ULTRA-VISUAL-jar.

## Установка
Jar положить в .minecraft/mods вместе с Fabric API (1.21.11). Папку проекта в mods НЕ класть.
